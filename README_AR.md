# N by N — إضافة غرفة تجربة 3D

## الملفات
- `index.html` و`style-v2.css`: واجهة المتجر مع نافذة التجربة.
- `store.js`: يحافظ على منطق السلة الحالي ويصدر حدثًا عند تحديثها.
- `tryon.js`: عرض 3D تفاعلي تجريبي باستخدام Three.js، مع تبديل رجل/امرأة وتحديث لون المجسّم عند إضافة منتج.
- `tryon.css`: تنسيق غرفة التجربة.
- `config.js`: إعداد Supabase الحالي؛ لم يُغيّر.

## ما الذي يعمل في هذه النسخة؟
1. زر «جرّب إطلالتك على مجسّم 3D» داخل السلة.
2. تحديث معاينة المجسّم عند تغيّر محتويات السلة.
3. تبديل مجسّم الرجل والمرأة وتدوير المشهد باللمس/الفأرة.
4. إظهار صورة آخر منتج مضاف واسمه وسعره.
5. بقاء عمليات تسجيل الدخول والطلب في كود المتجر الأصلي.

## ملاحظة مهمة عن الواقعية
هذه نسخة تشغيل أولية بمُجسّم mannequin هندسي تفاعلي؛ ليست تجربة قياس افتراضي واقعية بعد، ولا تجعل القماش يطابق الجسم أو المقاس تلقائيًا. للوصول إلى واقعية عالية نحتاج ملفات شخصيات وملابس 3D مرخّصة بصيغة GLB/GLTF ومطابقة/rigging لكل قطعة أو خدمة virtual try-on متخصصة. لا نعرض ذلك على أنه متوفر في هذه النسخة.

## الرفع إلى GitHub Pages من الهاتف
1. افتح مستودع `N_BY_N` في GitHub.
2. ارفع/استبدل الملفات `index.html`, `style-v2.css`, `store.js`, `config.js`.
3. أضف الملفين الجديدين `tryon.css` و`tryon.js` إلى جذر المستودع نفسه (بجانب `index.html`).
4. لا ترفع مجلد `N_BY_N_3D_tryon` كطبقة داخل الموقع؛ يجب أن تكون الملفات الستة في نفس المجلد الذي فيه `index.html`.
5. انتظر اكتمال GitHub Pages ثم افتح الموقع وأضف منتجًا إلى السلة. اضغط زر التجربة.
6. اختبر تسجيل الدخول وإتمام الطلب بعد الرفع.

## ملاحظة أمان
`config.js` يحتوي على publishable/anon key مخصص للمتصفح، وهو ليس service-role secret. يجب أن تعتمد الحماية على سياسات RLS صحيحة في Supabase. لا تضع مفتاح service_role في ملفات الموقع.
