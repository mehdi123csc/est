N BY N — حزمة الملفات القديمة والجديدة
========================================

المحتويات الرئيسية:
- index.html: واجهة المتجر السينمائية الجديدة.
- cinematic.css و cinematic.js: مؤثرات الحركة والعمق الجديدة.
- style-v2.css: ملف تنسيق أساسي مرفق كي تعمل الواجهة دون الاعتماد على ملف CSS مفقود.
- store.js: نسخة store_fixed.js التي كانت متاحة، مع الحفاظ على منطق المتجر والطلبات.
- admin.html و admin.css و admin.js: ملفات لوحة الإدارة.
- hero.jpg و men.jpg و women.jpg و logo.svg: صور الواجهة وشعار SVG احتياطي.
- old-version/: نسخ HTML وJavaScript القديمة المتاحة.
- config.example.js: مثال إعدادات Supabase آمن بدون مفتاح فعلي.

مهم قبل النشر:
1) انسخ config.example.js وسمّه config.js.
2) ضع مفتاح Supabase Publishable/anon الحالي في SUPABASE_KEY. لا تضع service_role أو أي مفتاح سري في الموقع.
3) هذه الحزمة تجمع أحدث ملفات N BY N التي كانت متاحة في جلسة العمل مع ملفات التصميم الجديدة. ملف style-v2.css الأصلي وملف logo.jpg الأصلي ونسخة config.js الفعلية لم تكن متاحة ضمن الملفات التي أمكن استرجاعها، لذلك أُرفق تنسيق أساسي وشعار SVG احتياطي وملف إعدادات نموذجي بدل اختلاق أسرار أو نسخ غير متوفرة.
4) لا تحذف أو تعدّل بيانات Supabase أو الطلبات الموجودة. اختبر النسخة على فرع/نسخة معاينة قبل استبدال ملفات الموقع المنشور.
5) تأكد من أن جداول Supabase وسياسات RLS وRPC الموجودة في مشروعك ما زالت متوافقة مع store.js وadmin.js قبل اعتماد النسخة.
