# N by N — Cinematic Fashion Website

## Version 1
A standalone, responsive fashion landing/storefront inspired by modern cinematic web design.

### Included
- Cinematic full-screen hero
- Scroll reveal animations
- Men / Women sections
- Product collection with filters
- Search overlay
- Shopping bag with localStorage
- Newsletter UI
- Responsive mobile navigation
- No build step required

## Deploy on GitHub Pages
1. Create a repository.
2. Upload `index.html`, `styles.css`, `app.js`.
3. Commit.
4. Open Settings → Pages.
5. Select the main branch and root folder.
6. Save.

## Deploy on Netlify
Drag the whole folder to Netlify Drop, or connect the GitHub repository.
